# Jiya Tours & Travels

Free static cab booking website with WhatsApp enquiry/quotation flow.

## Before publishing
Open `script.js` and change:

`const OWNER_WHATSAPP = "919999999999";`

to the owner's WhatsApp number in international format, without `+`, spaces or dashes.

Example for an Indian number: `919876543210`

## How it works
1. Customer opens the website.
2. Customer fills pickup, drop, date, time, cab type, passenger and contact details.
3. Customer clicks **Continue on WhatsApp**.
4. WhatsApp opens with a prefilled booking/quotation message.
5. Customer sends the message to the owner's WhatsApp.

No database, payment gateway or paid backend is required.

## Free publishing
This is a static HTML/CSS/JavaScript website and can be published free using GitHub Pages. No traditional hosting is required.
